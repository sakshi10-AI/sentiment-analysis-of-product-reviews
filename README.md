# Amazon Product Review Sentiment Analysis

## Overview

This project uses Natural Language Processing (NLP) and Machine Learning to classify Amazon product reviews as Positive or Negative.

The model uses:

- TF-IDF Vectorization
- Logistic Regression

## Dataset

Amazon Reviews Dataset

https://www.kaggle.com/datasets/bittlingmayer/amazonreviews

## Technologies Used

- Python
- Pandas
- Scikit-Learn
- KaggleHub
- Matplotlib
- Seaborn

## Workflow

1. Download Dataset
2. Data Preprocessing
3. TF-IDF Feature Extraction
4. Model Training
5. Model Evaluation
6. Sentiment Prediction

## Results

Accuracy Achieved: 88.11%

## Example

Input:

This product is amazing and worth every penny

Output:

Positive
